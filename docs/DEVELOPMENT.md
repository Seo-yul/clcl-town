# 클클 타운 개발 문서

클클 타운을 직접 실행하고 고치고 배포하는 방법을 적는다. 마을 소개와 조작 방법은 [README](../README.md) 에 있다.

클클 타운은 three.js 로 그린 3D 복셀 마을이다. 마을은 여러 구획으로 나뉘고, 구획마다 주인 이름이 떠 있는 농장이 하나씩 있다.
모든 농장에는 클라우드 클럽 구름 캐릭터가 하나씩 살고, 주인이 함께한 게임이 있으면 그 게임 캐릭터도 함께 산다.
닭, 토끼, 양, 오리 같은 동물은 광장에 산다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173 에서 열린다
npm run build    # dist/ 에 배포용 파일을 만든다
npm run preview  # 만든 dist/ 를 미리 본다
```

`dist/` 폴더는 정적 파일이므로 GitHub Pages, Netlify, 일반 웹 서버 어디에 올려도 된다.
경로를 상대 경로로 만들기 때문에 하위 폴더(예: `example.com/town/`)에 올려도 동작한다.

## 배포

`main` 브랜치에 push 하면 GitHub Actions(`.github/workflows/deploy.yml`)가 빌드해서 GitHub Pages 에 올린다.
주소는 https://devops.ai.kr/clcl-town/ 이다. `Seo-yul` 계정의 GitHub Pages 에 연결된 도메인을 그대로 쓰기 때문에,
https://seo-yul.github.io/clcl-town/ 으로 들어와도 이 주소로 넘어간다.
저장소의 Actions 탭에서 진행 상황을 볼 수 있고, 같은 탭에서 손으로 다시 배포할 수도 있다.

## 농장 주인 이름 바꾸기

`src/config.js` 의 `owners` 배열을 고친다. 앞에 있는 이름일수록 광장에 가까운 구획을 받는다.
이름 수에 맞춰 구획 수와 마을 크기가 자동으로 정해지고, 남는 구획은 연못 쉼터가 된다.

```js
owners: ['윤서율', '강형준', '김기석', /* ... */],
```

코드를 고치지 않고 확인만 하려면 로컬 개발 화면(`npm run dev`)의 주소 뒤에 이름을 붙인다.

```
http://localhost:5173/?owners=하늘,바다,구름이
```

배포된 사이트에서는 `?owners=` 를 무시한다. 받아 주면 누구나 우리 도메인으로 가짜 주인 이름이 보이는 링크를 만들 수 있고,
그 농장 방명록에 쓴 글이 이 저장소의 Discussions 에 쌓이기 때문이다.

## 농장 모습과 동물이 정해지는 방식

- 지금은 농장에 동물을 두지 않는다(`animalsPerFarm: 0`). 1 이상으로 바꾸면 게임 기록이 없는 농장에 그 수만큼 무작위 동물이 산다.
- 동물은 광장 분수 양옆과, 농장이 없는 빈 구획의 연못 쉼터에 산다.
- 기본값(`shuffleEachVisit: false`)에서는 이름마다 집, 헛간 색, 밭 작물이 항상 같다. 이름을 시드로 쓰기 때문이다.
- `shuffleEachVisit: true` 로 바꾸면 접속할 때마다 새로 정해진다.
- `seed` 값을 바꾸면 모든 농장의 구성이 한꺼번에 달라진다.

## 클라우드 클럽 구름

모든 농장에는 광장 분수의 클클이를 닮은 작은 구름이 하나씩 떠다닌다. 농장 정보 창에는 '☁️ 클라우드 클럽' 칩으로 나온다.
E 를 누르면 몽글하게 부풀고, git 명령어나 개발자 밈 대사를 말한다. 대사는 `src/models.js` 의 `CLUB` 에서 고친다.

## 함께한 게임

`src/config.js` 의 `plays` 에 함께한 게임을 한 판씩 적는다. 이 목록에 이름이 있는 농장에는 그 게임의 캐릭터가 산다.

```js
plays: [
  { game: 'holdem', players: ['윤서율', '윤서영', '박도연', '이주원', '박세현'] },
  { game: 'kraken', players: ['윤서율', '김동욱', '정장우', '조승아', '이서영', '고태현'] },
],
```

- 같은 사람이 같은 게임을 여러 판 하면 그 농장의 캐릭터가 판 수만큼 늘어나고, 농장 정보 창에 "2판"처럼 판 수가 나온다.
- 농장 이름표와 광장 안내판에는 구름과 게임 아이콘만 판 수 없이 나온다. 게임 이름은 농장 정보 창의 '함께한 게임'에 나온다.
- 명단에 없는 이름을 적으면 브라우저 개발자 도구 콘솔에 경고가 나온다.

지금 있는 게임은 다음과 같다. 이름, 아이콘, E 안내, 말풍선은 `src/models.js` 의 `GAMES` 에서 고친다.

| `game` 값 | 게임 | 캐릭터 | E 를 누르면 |
| --- | --- | --- | --- |
| `holdem` | 🃏 홀덤 | 스페이드 에이스 카드 | 카드가 뒤집힌다 |
| `kraken` | 🐙 노 터치 크라켄 | 주황 눈의 크라켄 | 촉수를 휘두른다 |
| `codenames` | 🕵️ 코드네임 | 검은 정장 요원, 빨간 팀 또는 파란 팀 넥타이 | 주변을 두리번거린다 |
| `lasvegas` | 🎲 라스베가스 | 빨간 카지노 주사위 | 한 바퀴 구른다 |

새 게임을 넣으려면 `GAMES` 에 항목을 더하고, 같은 파일의 `RIGS` 에 복셀 모델을 만드는 함수를 더한다.

## 머더 미스터리 캐릭터

머더 미스터리 시리즈 캐릭터 7명은 아직 아무 농장에도 배정하지 않았다. `src/config.js` 의 `roaming` 에 있는 캐릭터는
농장 사이 길을 한 명씩 구간을 나눠 돌아다닌다. E 안내는 모두 '수상한 인물에게 말 걸기'이고, 말을 걸면 '...' 만 남긴다.

| `game` 값 | 게임 | 캐릭터 |
| --- | --- | --- |
| `wendy` | 🤖 웬디, 어른이 되렴 | 앞머리로 눈을 가린 안드로이드 소녀, 한쪽 눈 아래 붉은 액체 |
| `bluemoon` | 🌙 몇 번이고 푸른 달에 불을 붙였다 | 표지의 남색 목판화 장미가 줄기로 걷는다 |
| `werewolf` | 🐺 늑대인간 마을의 축제 | 붉은 망토의 크림색 늑대인간, 붉은 유리병 |
| `eida` | 👑 에이다 | 금발에 붉은 왕관과 흰 담비 털 망토, 금 홀을 든 왕 |
| `giantbird` | 🦅 괴조는 깊은 탄식의 끝에 | 긴 깃털을 늘어뜨린 잿빛 거대한 새 |
| `hero` | ⚔️ 용사가 죽었다 | 등에 검이 꽂힌 세피아색 용사, 눈은 X |
| `suspect` | 🔍 서스펙트 게임: 클로즈드 서클 미스터리 | 그림자에 얼굴이 가린 후드 차림 용의자, 붉고 푸른 네온 |

누군가와 함께한 게임이 되면 `plays` 에 기록한다. 그러면 그 농장에도 캐릭터가 생긴다.
길을 돌아다니는 캐릭터를 없애려면 `roaming` 에서 뺀다.

## 농장 방명록 (giscus)

농장 정보 창 아래에 방명록이 있다. 글은 이 저장소의 GitHub Discussions 에 저장되며,
농장마다 "윤서율의 농장 방명록" 같은 제목의 Discussion 이 하나씩 생긴다. 첫 글이 달릴 때 giscus 가 만든다.
글을 쓰려면 GitHub 계정으로 로그인해야 한다.

처음 한 번은 GitHub 웹에서 다음을 해야 한다. API 로는 할 수 없다.

1. https://github.com/apps/giscus 에서 giscus 앱을 이 저장소에 설치한다.
2. 저장소의 Discussions 탭에서 카테고리 `방명록` 을 만든다. 형식은 **Announcement** 로 고른다.
   그래야 방문자가 Discussions 에 글을 직접 새로 만들 수 없고, 방명록 글만 달 수 있다.
3. https://giscus.app/ko 에 저장소 이름을 넣고 `방명록` 카테고리를 고르면 `data-repo-id`, `data-category-id` 가 나온다.
   이 두 값을 `src/config.js` 의 `guestbook.repoId`, `guestbook.categoryId` 에 넣는다.

`giscus.json` 은 방명록이 뜰 수 있는 사이트 주소를 정한다. 지금은 배포 주소(`devops.ai.kr`, `seo-yul.github.io`)와 로컬 개발 주소만 허용한다.
다른 도메인으로 배포하면 그 주소를 `origins` 에 추가해야 방명록이 뜬다.

`guestbook.titleFormat` 은 방명록에 글이 달린 뒤에는 바꾸지 않는다. giscus 가 이 제목으로 농장의 글을 찾기 때문이다.

방명록을 연 상태의 주소(`?farm=윤서율`)는 그 농장으로 바로 들어가는 링크가 된다.

방명록의 색과 글꼴은 `public/giscus-theme.css` 가 정한다. giscus 위젯은 이 파일을 배포된 사이트에서 읽는다.
로컬 개발 화면도 배포된 파일을 쓰므로, 이 파일을 고친 결과는 배포한 뒤에 보인다.
`devops.ai.kr` 앞의 Cloudflare 가 CSS 를 몇 시간씩 캐시하기 때문에, 빌드할 때 이 파일 내용으로 만든 버전 값을 주소 뒤에 붙인다(`giscus-theme.css?v=...`).
그래서 파일을 고쳐서 배포하면 주소가 바뀌고, 방문자는 바로 새 테마를 받는다.

## 광장의 안내판과 표지판

광장의 마을 안내판에서 E 를 누르면 농장 목록이 열린다. 목록 위 입력칸에 이름을 넣으면 목록이 줄어들고,
초성(`ㅇㅅㅇ`)으로도 찾을 수 있다. 하나만 남았을 때 Enter 를 누르면 그 농장 입구로 이동한다.
검색은 `src/ui.js` 의 `nameMatches` 가 맡는다.

광장 남서쪽의 GitHub 표지판 앞에서 E 를 누르면 `src/config.js` 의 `contributeUrl` 을 새 탭으로 연다.
값을 비우면 표지판을 세우지 않는다.

M 을 누르거나 오른쪽 위 지도를 누르면 큰 지도가 열리고, 지도에서 누른 곳으로 캐릭터가 바로 옮겨 간다.
누른 곳이 건물이나 나무, 울타리 위라면 `src/world.js` 의 `freeSpot` 이 그 둘레에서 설 수 있는 가장 가까운 자리를 찾는다.

조작 방법은 [README](../README.md#조작-방법) 에 있다.

## 배경음악

배경음악 파일은 `src/assets/bgm.m4a` 다. 같은 이름의 파일로 바꾸면 빌드할 때 새 파일 이름에 내용 해시가 붙으므로 캐시 걱정 없이 바로 바뀐다.
재생은 `src/music.js` 가 맡는다. 브라우저는 방문자가 클릭하거나 키를 누르기 전에는 소리를 내지 못하게 막으므로, '마을로 들어가기'를 누를 때 음악을 켠다.
농장 링크로 바로 들어와 클릭이 없었다면 첫 클릭이나 키 입력 때 켠다.
소리 크기는 Web Audio 의 gain 으로 조절한다. iOS 는 스크립트가 `<audio>` 의 볼륨을 바꾸지 못하게 막기 때문이다.
켜고 끈 상태와 볼륨은 브라우저의 localStorage(`clcl-music`, `clcl-music-vol`)에 남아 다음 방문 때도 유지된다. 탭을 떠나면 음악을 멈췄다가 돌아오면 다시 튼다.
볼륨 막대는 컴퓨터에서만 보인다. 터치 화면(`pointer: coarse`)에서는 기기의 볼륨 버튼이 같은 일을 하므로 🔊 버튼만 두고, 저장된 볼륨 대신 늘 기본값 40 으로 튼다. 막대가 없으니 예전에 낮춰 둔 값이 남으면 다시 올릴 방법이 없기 때문이다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `src/config.js` | 마을 이름, 농장 주인 이름, 함께한 게임, 무작위 설정, 기여하기 주소 |
| `src/world.js` | 구획 배치, 길, 농장, 광장, 연못 |
| `src/models.js` | 동물, 게임 캐릭터, 플레이어, 나무, 구름 모델과 이름·울음소리·말풍선 |
| `src/animals.js` | 동물과 게임 캐릭터가 돌아다니고 E 에 반응하는 동작 |
| `src/player.js` | 캐릭터 이동, 충돌, 점프 |
| `src/sky.js` | 시간대별 하늘과 조명, 떠다니는 구름 |
| `src/ui.js` | 이름표, 말풍선, 미니맵과 큰 지도, 정보 창, 농장 검색, 모바일 조작 |
| `src/music.js` | 배경음악 재생, 켜고 끄기, 볼륨 |
| `src/assets/bgm.m4a` | 배경음악 |
| `public/favicon.svg` | 구름 파비콘 |
| `public/apple-touch-icon.png` | iPhone 홈 화면 아이콘. 파비콘을 하늘색 바탕에 그린 180px 그림이다 |
| `public/og.jpg` | 링크 미리보기 그림. `docs/screenshot.jpg` 를 복사했다 |
| `public/giscus-theme.css` | 방명록 색과 글꼴 |
| `public/fonts/` | 갈무리 글꼴. 사이트와 방명록이 함께 쓴다 |
